# Ugmuls 5.5e Automation v1.2.1

Character creation and character-sheet compendium tools now live in Ugmuls Character Workshop v0.2.1.

## Highlights

- **Guided character creation.** Create Player and wizard continuation are available in the Actors directory with Character Workshop enabled. Existing wizard progress carries forward.
- **Character-sheet tools.** Character Workshop opens filtered compendiums from Add Item and Add Spell, supports selecting multiple spells, and can load missing unprepared class spells for eligible casters. Existing world settings carry forward.

See the changelog in the repository for the full list of feature changes.

## Requirements and updating

- **Foundry VTT 14**, verified build **14.370**.
- **D&D5e 6.1.0 or later** (verified on 6.1.0).
- **Automated Conditions 5e** and **Dice So Nice!** must be installed and enabled. Keep an active GM connected for shared resource, effect, and HP operations.
- Official **Player’s Handbook (2024) 3.0.0** remains the target for PHB class automation. Updating the book leaves existing character items in place. Review owned features through your usual character-content workflow if they still use older item layouts.
- Enable **Ugmuls Character Workshop v0.2.1** to keep using character creation and the sheet compendium tools. Back up your world and refresh GM and player clients after updating.
