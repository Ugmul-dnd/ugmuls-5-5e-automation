# Wall of Thorns

Built-in Region recipe uses native PHB activities without rewriting book data or shapes.

- Initial Create Wall / Create Circle: Dexterity save, 7d8 Piercing damage at level 6, half on success.
- Entry / target turn end: Traversal Save (dMiM7Qec4keU3w7B), Dexterity save, 7d8 Slashing damage, half on success; once per target per turn.
- Both stages retain native +1d8 per slot above 6.

The initial wall/circle activity IDs are registered for target turn allowances but the initial Piercing save card is not reused for traversal. Follow-up targets share the separate traversal card for that Region/turn. Region execution explicitly passes the original slot-level scaling increase and uses no additional resources, template or concentration start. The normal save prompt, owner/GM fallback, pending recovery, resistance and HP application workflows remain in use. Existing local Region overrides are preserved; Reset to Default opts into this recipe.

Native placement dimensions and damage parts are unchanged. Four-foot movement expenditure per foot traveled and line-of-sight blocking remain GM/table-managed; no ordinary two-times Difficult Terrain substitute is added. No creature trigger or movement-distance damage counter is attached.

Fresh-cast validation: both wall/circle initial Piercing saves; later entry/end-turn Slashing saves; native half damage, resistance and slot scaling; no duplicate entry/end-turn trigger in one turn; separate placement/traversal cards; multiple targets sharing a traversal card; pending save/damage recovery; concentration cleanup and manually adjusted Region shape.
