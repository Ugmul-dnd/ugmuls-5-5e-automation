# Monster grapple escapes - first batch

21 shared recipes across 24 monsters / 25 native feature variants.

- Aboleth / Giant Squid / Otyugh - Tentacle / Grappled
- Ankheg - Bite / Grappled
- Barbed Devil - Claws / Grappled
- Bugbear Warrior - Grab / Grappled
- Chuul / Glabrezu - Pincer / Grappled
- Crocodile - Bite / Grappled & Restrained
- Giant Crab - Claw / Grappled
- Giant Crocodile - Bite / Grappled & Restrained
- Giant Octopus - Tentacles / Grappled & Restrained
- Giant Scorpion - Claw / Grappled
- Grell - Paralyzing Tentacles / Grappled
- Griffon - Rend / Grappled
- Mimic - Adhesive (Object Form Only) / Grappled
- Mimic - Pseudopod / Grappled
- Roc - Talons / Grappled & Restrained
- Tyrannosaurus Rex - Bite / Grappled & Restrained
- Vampire - Grave Strike (Vampire Form Only) / Grappled
- Vampire Spawn - Claw / Grappled
- Mezzoloth - Claws / Grappled and Restrained
- Grick / Grick Ancient - Tentacles / Grappled
- Mind Flayer - Tentacles / Grappled and Stunned

Reuse native applied effects and Escape Check DCs. Target turn-start cards are optional action checks, never automatic rolls. Connected owners receive the prompt, falling back to GM. Choose STR Athletics or DEX Acrobatics where listed by the native check. Mimic escapes have Disadvantage. After dice, success removes only the tracked source effect, including its native combined statuses; other grapplers and Grell poison survive.

Initial hit effects use existing auto/manual Apply settings; do not invent an initial save. Mimic Adhesive touch application remains manual; once its effect is applied, escape tracking works. No movement, grapple capacity, suffocation, swallowing, ongoing damage or alternate destruction handling is automated. Existing spell escape checks remain Athletics-only. Native expiry and stat changes are preserved, and source book data is unchanged.

Reload and test fresh grapple effects: optional start-turn card, skill choice, Mimic Disadvantage, native DC, cancel/retry, DSN timing, successful removal, failure retention, two grapplers, separate Grell poison, and player/GM routing.
