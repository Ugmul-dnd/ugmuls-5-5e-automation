# Remaining straightforward monster repeat saves

Six new recipes across six monster actor variants:

| Feature | Repeat save | Tracked condition |
| --- | --- | --- |
| Harpy Luring Song | Wisdom, victim turn end | Charmed & Incapacitated |
| Chasme Drone | Constitution, victim turn end | Unconscious |
| Faerie Dragon Adult / Youth Euphoria Breath | Wisdom, victim turn end | Incapacitated |
| Revenant Vengeful Glare | Wisdom, victim turn end | Frightened, or Frightened & Paralyzed |
| Sphinx of Valor Second Roar | Wisdom, victim turn end | Paralyzed |

Recipes reuse native prepared source DCs, applied effect status/stat changes, actor ownership routing and normal manual/automatic initial effect settings. Native timed expiry remains in control except Harpy's imported one-round effect: applied copies receive no arbitrary round limit and retain their native concentration dependency. Source book/world items are unchanged.

Save-only helper cards create no repeated damage, effect, template, concentration or resource expenditure, and suppress cast animations. Success clears the tracked effect after Dice So Nice. Revenant's two native effects share one save per target/source cast; success clears linked effects from that cast while retaining other sources. No curse-eligibility inference or initial profile selection is added.

Sphinx First Roar does not explicitly grant a repeat save, so no repeat recipe is added for Frightened. Third Roar Prone remains native. Roar sequence selection/counters remain manual. Both Faerie Dragon ages use the shared native Euphoria save; random movement remains manual.

Harpy movement, dangerous terrain and damage-triggered extra saves, Chasme damage/Holy Water/automatic-success exceptions, demon immunity and 24-hour success-immunity bookkeeping remain manual in this end-turn-save pass. Native effect durations handle ordinary timed limits. These are repeat-save additions, not complete automation of every sentence of each feature.
