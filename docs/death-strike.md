# Death Strike

Enable Death Strike Assistance under Rogue options. A 2024 Death Strike feature with its native save activity is required. First-round weapon Sneak Attack hits automatically prompt its Constitution save, using the feature’s configured Dexterity-based DC. Fresh attack cards record round-one context independently of Assassinate’s setting.

The native activity contains another Sneak Attack damage roll. Generated save helpers remove that damage, effects and consumption; the original weapon/Sneak Attack/Cunning Strike/Assassinate rolls remain unchanged. Cancellation and preview do not create a save or spend resources.

Automatic and manual damage application wait for the save and animation coordination. Failure seeds the affected target’s multiplier to 2; success seeds normal damage. Native resistance/immunity calculations still apply. A recorded Uncanny Dodge or Elemental Rebuke halves the resulting amount (so double plus half returns to normal), and explicit multiplier controls remain available after the default is seeded.

Save corrections before application update the factor. Applied attack damage locks Death Strike save adjustments until damage is undone. Undo/reapply retains the same save without creating another one. Cunning Strike’s post-damage effects and Envenom’s separate save damage remain in their existing order. No extra action, Reaction, charge, initiative changes or movement hooks are added. Keep an active GM connected for save creation and managed application.
