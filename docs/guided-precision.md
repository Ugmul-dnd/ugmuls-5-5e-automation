# Guided Precision

Enable Cartographer: Guided Precision under Artificer settings. With the feature on the caster, damage configuration offers Guided Precision when the single recorded target has an active Faerie Fire effect belonging to that caster. Other casters’ Faerie Fire does not qualify. Uses the user-selected Faerie Fire branch; this automation does not independently grant the Cartographer spell-list branch.

Choose Yes to add the source feature’s Intelligence formula to one damage roll. The choice defaults to Yes when eligible; choose No to opt out. Mixed damage can select one native part; use that part’s damage type, keep original dice, and never double the flat bonus on a critical. Native feature uses recover each combat turn, and a GM-validated turn stamp prevents simultaneous uses from separate clients. Preview/cancel spends nothing; failed evaluation refunds its own claim. A shared multi-target damage roll is excluded so unaffected recipients never receive the bonus.

While Guided Precision is present and the caster’s active concentration is solely their Faerie Fire, native damage-triggered concentration challenge prompts are suppressed. Other concentration spells, explicit manual rolls, and prompts to end concentration remain native.

Local verification covers source identity, disabled effects, once-per-turn uses, authority and failed-roll rollback, actual configured-dialog preview/finalization/commit, damage types and critical handling, and concentration scope. Live Foundry testing remains pending.
