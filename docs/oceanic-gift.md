# Oceanic Gift and Wrath activation

Clicking either Oceanic Gift activity or the main feature card opens **Select Targets for Ocean Gift**. The dropdown lists friendly, available creatures on the current map within the native 60-foot gift range; friendliness represents the user choosing a willing recipient. **Apply to self too** is enabled only with at least two Wild Shape uses and a different recipient. Confirm uses the native one- or two-use pool; Cancel spends nothing. Wrath and Stormborn activation entry points use the same popup. Without Oceanic Gift, only Self Target and Confirm/Cancel are offered. No aura or Region is placed.

The active GM revalidates ownership, source token/scene, recipient, current resources and feature availability. A native non-rolling utility clone consumes the real Wild Shape pool and the caster’s Bonus Action once. Native Ocean Spray and owned Stormborn changes are applied to one or both recipients, retaining caster, bearer, source item, source token and activation instance. The caster’s prior grants are disabled, including recorded recipients on other maps. Failed application restores the previous grants and refunds native consumption. Activation request receipts prevent duplicate spending.

After activation, a second popup offers one optional enemy per emanation, in separate sections for a double manifestation. Targets must be in that bearer’s native Wrath range and remain valid on GM-side confirmation. A shared overlapping enemy is recorded once. Confirm creates one native save group and one shared damage roll/card for all selected targets, using the original caster’s DC and Wisdom. No additional Wild Shape use, Bonus Action or area placement is required. Skip Initial Damage leaves the already confirmed buffs active. GM reservations prevent duplicate initial use and roll back a failed native usage.

Application-time BA prompt cards are suppressed. At each bearer’s turn start, post **BA - Wrath of the Sea** as a private chat action for all GMs and the bearer’s owners. No recent-chat scan is used. The effect records its current prompt ID; changed/expired effects refresh that exact card through the shared queue. Token-turn and instance deduplication prevent duplicate prompts. The current combatant’s existing buff prompt is recovered at ready/canvas-ready. This includes ordinary Manifesting Ocean Spray applications with a resolvable native source.

Clicking requires exactly one other visible eligible creature within the original Druid’s native Wrath range. It uses the bearer’s location and permissions, the Druid’s native Wisdom-based Cold formula and spell save DC, and the standard save/damage/Apply/Undo workflows. A GM-authorized reservation prevents simultaneous player/GM clicks. Initial damage is handled by the post-cast popup; later chat actions require the bearer’s current turn and normal Bonus Action. No further Wild Shape use is spent. Pending-cast cancellation refunds the reservation; committed or newer uses cannot be reopened by old rollbacks. Outside combat, ordinary subsequent uses remain available without inventing a permanent turn lock. Push remains manual.

Tests cover friendly/range and ownership validation, one/two native resource costs, popup cancellation/checkbox gating, all activation entry points, original-caster DC/Wisdom, native Stormborn effects, GM/owner whisper recipients, prompt deduplication, initial and later turn rules, out-of-range targets and reservation rollback. In-game GM/player verification remains pending.

The main Item.use interception registers as a libWrapper MIXED handler when available. Sea activation opens its custom selection; all other item uses delegate through the wrapper chain, including Monk’s Combat Details’ spell bookkeeping. A direct chained fallback is used only without libWrapper.

Wrath initial and repeat save/damage cards default to recorded target mode, including grouped summaries, so save outcomes remain associated with the chosen recipients. Initial-target dialogs run outside the mutation queue. Only source-linked effects and their activation card are examined; no recent-chat refresh loop is added.
