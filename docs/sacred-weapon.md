# Sacred Weapon

Enable **Sacred Weapon Assistance** under Paladin settings. On an owned equipped melee weapon’s attack configuration, click **Activate Sacred Weapon**. The native Devotion feature and Channel Divinity resource are required.

Activation spends one Channel Divinity use and applies the PHB’s native enchantment. The current attack prompt closes and reopens through native attack configuration so the Charisma bonus is included in this attack and AC5e recalculates normally. Choose your attack mode in that refreshed prompt. The native enchantment supplies the normal/Radiant damage choice.

A temporary actor effect named **Sacred Weapon — [weapon]** controls the enchantment and light for 10 minutes. Disable it to stop the benefits; re-enable it while its duration remains to restore them without another use. Deleting the effect cleans up the enchantment and light. Unequipping or losing the weapon disables the controller. Activating another weapon replaces the previous controller.

The weapon’s bearer emits 20-foot bright / 40-foot dim light (converted in metre scenes). Existing brighter light is preserved. Cleanup restores the previous bright/dim distances only if those distances still match the module’s applied values, preserving unrelated manual light changes and animation/color settings. A connected GM synchronizes player effect toggles and lighting.

Activating the feature spends its use even if the subsequent attack is canceled. It does not spend another Action, Bonus Action or Reaction through this assistance. Existing native enchantments from other sources are preserved.
