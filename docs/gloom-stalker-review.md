# Gloom Stalker review

2024 Player's Handbook, reviewed October 27, 2026.

- Dreadful Strike: optional Yes/No in confirmed weapon-hit damage configuration (default No). Native activity use, Wisdom-based use limit/recovery, native scaling (2d6 to 2d8), critical support, once per combat turn. Preview and cancellation spend nothing. Outside combat only the resource limit applies.
- Ambusher's Leap: active GM grants +10 speed on the Ranger's first combat turn and removes the temporary effect on turn change or combat deletion. Combat records prevent repeated grants on reload or initiative rewind. Existing active Leap is reused to avoid stacking.
- Initiative, Darkvision, Iron Mind and granted spells remain native.
- Stalker's Flurry: Mass Fear Yes/No beneath Dreadful Strike, default No, disabled unless Dreadful Strike is selected. Yes posts the native Wisdom save as the original damage is published, centered on the original target (10 feet); failed saves apply Frightened until the start of the Ranger's next turn. No adds a Sudden Strike button to the rolled damage card: select a different creature within 5 feet of the original target and within the weapon's range, then roll an attack with the same weapon. Does not spend another Dreadful Strike use; canceled attacks release the button.
- Mass Fear affects creatures in the area, including allies, as written; it does not select enemies only. No persistent Region is needed. Shared save prompts, visibility, effect application and Undo settings still apply.
- Conditional Umbral Sight invisibility and Shadowy Dodge remain manual for now.
