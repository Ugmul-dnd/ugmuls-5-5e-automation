# Indomitable

Enabled under Fighter automation. On a failed saving throw with a recorded DC, click Indomitable (+Fighter level). Spend one native Indomitable use, replace the d20 with one new d20 and add Fighter level while retaining existing save modifiers and bonus dice. Keep the new result even if it is lower or still fails. No Reaction, ability-check prompt or spell slot is used.

The reroll uses a single d20 independent of the original Advantage/Disadvantage mode, matching the module’s existing reroll handling. Other rolls on the card and recorded targets/DC remain unchanged. A roll can use Indomitable once. Native feature scaling and Long Rest recovery remain responsible for available uses.

The active GM arbitrates owning-player clicks. The new result is published after dice animation synchronization. Applied damage/effects lock corrections until Undo; failed commits restore the resource. Broken concentration and automatic success/failure helpers are excluded. Unknown-DC saves and 2014 feature versions remain manual. Tactical Mind remains manual.
