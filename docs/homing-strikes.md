# Homing Strikes

Enabled by default under Rogue automation. Soul Blades and Soulknife Psionic Power must be owned by the attacker. On a missed Psychic Blade attack, click Homing Strikes to add the current native Psionic Energy Die. The die is spent only if the attack hits; a natural one remains a miss. Each attack allows one attempt. Both main and bonus Psychic Blade attacks qualify.

The original attack dice and targets remain intact. A corrected hit resumes the normal damage prompt. Undo applied damage/effects before adjusting a roll. Unknown target AC and multiple-target attacks remain manual. Psychic Teleportation remains manual.
