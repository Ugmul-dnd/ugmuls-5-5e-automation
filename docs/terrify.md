# Strike Fear — Terrify

Scion of the Three owners with Strike Fear can select Terrify in the existing Cunning Strike damage configuration. It costs one Sneak Attack die, deducted before critical scaling, and can be combined with another distinct choice through Improved Cunning Strike.

After damage is applied, the native Wisdom save is prompted. A failed save applies Frightened for up to one minute. Repeat saves occur at each target turn end, ending the effect on success without extra costs. While that effect remains active, its originating Rogue has Advantage on attacks against the affected creature. AC5e supplies normal cancellation; a native fallback is available without AC5e. Other attackers receive no Terrify Advantage.

All other Scion features remain manual.
