# Vow of Enmity

Enable **Vow of Enmity Assistance** under Paladin settings. In weapon/unarmed attack configuration, target one visible creature within 30 feet and click **Activate Vow of Enmity**. This spends one Channel Divinity use and reopens the native attack prompt so AC5e includes the new Advantage source. Activation assumes the Attack action on the Paladin’s own combat turn; it does not spend a Bonus Action or Reaction.

One temporary effect on the Paladin stores the marked creature’s Actor and token references for one minute. Advantage applies only against that creature, including linked tokens representing it, and still cancels normally with Disadvantage. Existing Vow Advantage applies to all attack rolls, including spell attacks; activation is offered only on weapon/unarmed attacks. Range/visibility restrictions apply when activating or transferring, not to later attacks against the existing mark.

If the marked creature is currently at 0 HP, **Transfer Vow of Enmity — Free** can mark a new visible creature within 30 feet. Transfer changes only the target and preserves the original remaining duration. If the mark is still alive, **New Vow — Spend Channel Divinity** starts a new one-minute Vow instead. Missing/deleted targets are not assumed to be at 0 HP.

Disable/delete/expiry stops Advantage. Stale attack prompts are rejected if their Vow mark changes before submission. The active GM validates player requests and resource use; the attack prompt remains on the clicking client. No movement hooks, scene-wide target searches or historical chat refreshes are added.

Use the attack-config button for this automation. Existing native/manual Vow effects on enemy actors are not converted into source control effects. Activating Vow spends its use even if the subsequent attack is canceled.
